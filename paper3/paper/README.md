# What Must a Channel Express? — paper package

Venue-adaptable LaTeX source. Extends the GameSec poster and the Zenodo preprint
(10.5281/zenodo.20792312), both cited as prior work.

```
main.tex          venue driver — THE ONLY FILE YOU EDIT TO RETARGET A VENUE
preamble.tex      packages + macros, shared across venues
sections/         one file per section, venue-independent
figures/          4 vector figures + the monitor cost curve
refs.bib          bibliography (48 entries, all cited keys resolve)
Makefile          `make` -> main.pdf
```

## Build

```bash
make            # or: latexmk -pdf main.tex
```

## Retargeting a venue

Edit only the **VENUE BLOCK** at the top of `main.tex`.

| venue | documentclass | bibliography style | also do |
|---|---|---|---|
| Springer LNCS (GameSec, ESORICS) | `[runningheads]{llncs}` | `splncs04` | current default |
| ACM (CCS, AsiaCCS, AIES) | `[sigconf]{acmart}` | `ACM-Reference-Format` | replace `\institute{}` with `\affiliation{}`; drop `\titlerunning`/`\authorrunning`; ACM wants `\begin{abstract}` before `\maketitle` |
| IEEE (S&P, EuroS&P) | `[conference]{IEEEtran}` | `IEEEtran` | replace `\institute{}` with `\IEEEauthorblockA{}`; drop `\orcidID{}` |
| NeurIPS / ICML workshop | `{article}` + venue style file | `plainnat` or venue default | add the venue `\usepackage{}`; drop `\institute{}`, `\titlerunning`, `\authorrunning` |
| arXiv | `[11pt]{article}` | `plainnat` | as above |

`\orcidID{}`, `\institute{}`, `\titlerunning{}` and `\authorrunning{}` are LNCS-only.
They are confined to `main.tex`; no section file uses them.

### Anonymising for double-blind review

Replace the `\author`/`\institute` block in `main.tex` with the venue's anonymous form
and remove the acknowledgement of the artifact URL in the reproducibility appendix.
Nothing in `sections/` identifies the authors.

label, or marker shape), so no figure depends on colour alone.

## Two gaps stated in the paper

1. **No same-model bridge run.** The new experiments ran on a self-hosted
   Qwen2.5-14B, not on the models behind the prior work, so the ladder *generalises*
   the published pattern rather than *calibrating* against it. This matters more than
   usual because P1 found the menu-signal result reversing sign across model scales.
2. **L5's fidelity is measured on neutral text**, not on deployment snapshots. The
   paper's own methods section is the finding that neutral fidelity does not predict
   deployment fidelity, so the latent nulls do not separate "framing is text-specific"
   from "the link is unfaithful on game messages."

Both are in `sections/12_limitations.tex` and neither is glossed.
